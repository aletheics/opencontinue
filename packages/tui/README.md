# @opencontinue/tui

**Why:** a terminal client should be a package, not a mode inside the CLI.

**Owns:** an inline Claude Code-style terminal UI: saved-provider auto-start, a condensed startup banner (three-row coral block mark, bold name with dim version, dim model/provider, dim workspace, no welcome line); completed transcript written to terminal scrollback through Ink `Static`, `›` prompts, `● Tool(args)` blocks with two-space header continuation, dim `⎿` gutters with normal-brightness output, colored diffs, compact output hints, `(No output)`, and bash `(timeout …)`/cwd-reset notes, a 120ms `✻` glyph cycle with a shimmering coral spinner verb that fades to error red after 3s of silence and hides timer/tokens until 30s, past-tense completion lines with done time, `⏵⏵` permission-mode line, queued messages, provider/model/session pickers, permission dialogs with preview diffs, markdown-style assistant output with a white `●` dot and a two-column indented body (`-` lists, bold white headings, `▎` quotes, `---` rules, blue inline code, styled bold/italic/strikethrough/links that survive wrapping, and borderless syntax-highlighted fenced code), a height-clipped live assistant viewport, cursor-aware multi-line input, `ctrl+r` history search, `@file` completion that lists directories with the platform separator and keeps the menu open after completing one, and a workspace/git status line. There is no alternate screen and no bordered body/input.

**Files:** `index.tsx` owns state, screens, and event wiring; `components/` holds Welcome, Transcript, Picker, Prompt, Input, SlashMenu, and PermissionPrompt; `composer/` holds pure slash, history, and `@file` logic plus the editor feature folder; `session/` holds transcript partitioning, labels, and workspace info; `providers/` holds picker filtering; `permissions/` holds the decision rule and prompt controller; `hooks/` holds terminal integration; `status/` holds token/duration formatting; `transcript/format/` has one formatter per concern (wrap, markdown, diff, tool, transcript); `timeline.ts` reduces session events; `theme.ts` holds color tokens.

**Public API:** `runTui`, `App`.

**Allowed imports:** client, local-client, config, core, protocol, providers, tools.

**Must not:** import `apps/cli` or `apps/server`.

**Keys:** type to filter providers or models; `esc` clears the filter or returns to chat; typing `/` opens a filterable command menu (`↑/↓` select, `Tab` complete, `Enter` run, `Esc` close); typing `@` opens workspace file and directory completion (`↑/↓` select, `Tab`/`Enter` insert, `Esc` close; directories show the platform separator and complete to a trailing slash); `ctrl+o` opens the full expanded transcript; `shift+tab` cycles permission mode; `esc` aborts a run; `up`/`down` recall input history; `ctrl+r` opens a filterable history search; `ctrl+d` exits when the input is empty. The input supports `left`/`right`, `home`/`end`, `delete`, `ctrl+a`/`ctrl+e`, `ctrl+u`/`ctrl+w`/`ctrl+k`, and multi-line entry with `shift+enter` (or `alt+enter`/`ctrl+enter` on terminals that report modifiers). Messages submitted while a run is active are queued. A permission dialog shows the tool detail and, for writes/edits, a preview diff: `y` allows once, `a` allows that tool for the session, `n` denies.

**Slash commands:** `/help`, `/clear`, `/model`, `/provider`, `/resume`, `/mode`, `/status`, `/exit`.

**Tests:** `src/index.test.tsx` covers provider selection, type-to-filter pickers, slash-menu filtering and completion, key entry, session resume labels, the permission dialog with a preview diff, `ctrl+r` history search, `@file` completion, the workspace/git status line, the startup banner in a live app, a clipped live assistant, the full provider → model → chat loop, and repeated help output; `src/components/Welcome.test.tsx` covers the condensed banner, the narrow-terminal model/provider split, and truncation; `src/components/SpinnerLine.test.tsx` covers the 30-second timer/token gate, narrow-terminal dropping, and tips; `src/status/*.test.ts` cover glyph cycles, stall colors, compact numbers, and duration formatting; `src/transcript/format/wrap.test.ts` covers display-width and word-boundary wrapping, including CJK columns; `src/transcript/format/inline.test.ts` covers inline markdown spans and span-aware wrapping; `src/transcript/format/highlight.test.ts` covers the fenced-code tokenizer; `src/composer/editor/*.test.ts` cover cursor editing and viewport math; `src/timeline.test.ts` covers tool/assistant interleaving, diffs, and usage; `src/transcript/format/*.test.ts` cover wrapping, markdown, tool headers, diffs, and transcript lines.

**Startup:** a saved provider/model with credentials opens chat directly; otherwise the provider picker runs. The startup banner is a durable transcript item, so `/clear` and `/resume` print a fresh banner.

**Transport:** the App uses `OpenContinueClient`. It defaults to `LocalSessionClient` from `@opencontinue/local-client`; `--url` selects `HttpSessionClient` and lets the server own provider/model/transcript state. It never calls `runAgent` or owns a permission gate.
