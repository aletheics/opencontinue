# OpenContinue Session Rules

- Read a file before editing it.
- Prefer small, focused changes. Do not refactor unrelated code.
- Keep every path inside the workspace.
- Ask before destructive commands or ambiguous requirements.
- Never print or commit secrets.
- Use `glob` and `grep` to locate code; use `read` before `edit`.
- Run tests when you change behavior.
- Answer in the user's language.
